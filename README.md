# University Student Record and Campus Route Management System

## Project Overview
This Java console application is developed for the CIT300 Data Structures and Algorithms module. It effectively manages university student records using linear data structures (Linked Lists, Stacks, Queues), non-linear data structures (BST), and Hashing, while modeling campus locations and routes using a Graph with BFS traversal.

## Features Implemented
1. **Student Record Management:** Add, update, delete, and display student records using a Singly Linked List.
2. **Action History Tracking:** Track recent system actions using a Stack.
3. **Service Requests Management:** Handle student service requests using a Queue.
4. **Record Sorting and Searching:** Organize records using a Binary Search Tree (BST) and fast lookups using Hashing.
5. **Campus Network Mapping & Traversal:** Manage campus locations, roads/connections, and traverse routes using Breadth-First Search (BFS).

## How to Run
1. Open the project folder in any Java IDE (e.g., IntelliJ IDEA, Eclipse, VS Code).
2. Ensure all 7 Java files (`Student.java`, `StudentLinkedList.java`, `HistoryStack.java`, `ServiceQueue.java`, `StudentBST.java`, `CampusGraph.java`, and `Main.java`) are in the same directory.
3. Run the **`Main.java`** file to launch the interactive console menu.
